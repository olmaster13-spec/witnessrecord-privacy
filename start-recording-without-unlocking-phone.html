Start recording video without unlocking your phone

One press, and a stop gesture that is hard to trigger by accident.

In a tense moment you will not unlock a phone, find an app and tap through a menu. Witness is built to start recording in one press, and to be hard to stop by mistake. This page lists the ways to start it and how to set them up. Written by the developer of Witness Camera, so read it with that in mind; where another approach is better, it says so.

Short answer. On iPhone, Witness can start from the Action Button (iPhone 15 Pro and newer), a Lock Screen widget or a Siri phrase. On Android, it can start from a Quick Settings tile, a home-screen widget or an assistant shortcut, and from an opt-in power-button double press. To stop, you triple-tap and then press and hold, which is deliberately awkward so it is not triggered by accident or by someone grabbing the phone. Set it up and practise before you need it.

On iPhone

  • Action Button on iPhone 15 Pro and newer. Settings includes step-by-step setup.
  • Lock Screen widget, so you can start from the lock screen.
  • Siri phrase, hands-free.

On Android

  • Quick Settings tile, the primary route, which works from the lock screen.
  • Home-screen widget.
  • Assistant or app shortcut.
  • Power-button double press, opt-in, off by default, because Android routes that gesture to camera apps only.

Stopping, on purpose, is harder

Triple-tap, then press and hold. The app walks you through this once on first run. It is deliberately awkward so that a recording cannot be ended by accident or by someone who grabs the phone.

Set it up properly

  1. Connect your storage first. Nothing uploads until you do.
  2. Choose your start method and use it once.
  3. Practise the stop gesture.
  4. Record for 30 seconds and check the footage appeared in your storage.

Questions

Can I start Witness without unlocking my iPhone?

Yes. Use the Action Button (iPhone 15 Pro and newer), a Lock Screen widget or a Siri phrase.

What are the Android start options?

A Quick Settings tile, a home-screen widget, an assistant shortcut, and an opt-in power-button double press.

How do I stop a recording?

Triple-tap, then press and hold. It is deliberately awkward so it cannot be triggered by accident or by someone grabbing the phone.

Do I need to set anything up first?

Yes. Connect storage and test it. An app that has not been configured will not save anything off the phone.
